## 关于 BearPassword

BearPassword 是一款**简洁、安全、专业**的密码管理工具，帮助你集中保管登录凭据，并在需要时快速、安全地使用它们。

- **桌面端 + 浏览器扩展**：在桌面端管理保险库，在浏览器中一键自动填充，数据同源、体验连贯
- **客户端加密**：保险库内容在本地用安全密钥加解密，服务端仅存密文，明文密码只在解锁后出现
- **自动锁定**：闲置一段时间后自动锁定，离开电脑也能保护敏感数据
- **多语言与主题**：支持中文 / 英文 / 日文，内置多款浅色与深色主题

无论你是日常上网登录，还是管理多个账号，BearPassword 都希望成为你可以安心托付密码的那把「钥匙」。
