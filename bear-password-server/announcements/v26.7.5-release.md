# BearPassword v26.7.5 升级公告

## 版本概览

BearPassword **v26.7.5** 已发布。本次更新带来**网页端**、多项稳定性修复，以及官网与打包体验优化。

---

## 新功能

### 网页端正式上线

无需安装桌面应用，在浏览器中即可管理密码库。

- 访问地址：[https://bear-password.xuewei.fun/app](https://bear-password.xuewei.fun/app)（官网首页 Hero 区「进入网页端」）
- 支持登录 / 注册 / MFA / Emergency Kit 全流程
- 密码库增删改查、收藏、最近访问、Dashboard 统计
- 锁屏、自动锁定、剪贴板定时清空
- 设置：账户、安全、外观、关于；可选「在此浏览器记住主密码」
- **移动端适配**：底部 Tab 导航、密码库栈式详情、全屏编辑弹窗

> 网页端与桌面端、浏览器扩展**数据互通**（同一账号同步），但**不替代**扩展的网页自动填充能力——日常上网登录仍建议「桌面端 + 扩展」配合使用。

### 官网更新

- 界面优化，新增**开源专区**展示
- 首页增加「进入网页端」入口

## 升级方式

### 桌面端（macOS / Windows）

从 [官网下载页](https://bear-password.xuewei.fun/#download) 下载最新安装包，覆盖安装即可，数据与设置会自动保留。

### 浏览器扩展（Chrome / Edge）

1. 打开 `chrome://extensions`（或 Edge 扩展管理页）
2. 开启「开发者模式」
3. 下载最新 `BearPassword-Extension.zip` 解压后，点击「加载已解压的扩展程序」选择 `dist` 目录  
   — 若已通过商店安装，等待商店自动更新或手动更新

### 网页端

无需安装，刷新 [https://bear-password.xuewei.fun/app](https://bear-password.xuewei.fun/app) 即可使用最新版本。

## 使用提示

- **网页端用户**：首次使用请妥善保存 **Emergency Kit**；清除浏览器站点数据会导致本地安全密钥丢失
- **扩展用户**：网页填充仍依赖桌面端已解锁；桌面端未运行时，加密条目无法在网页中填充
- **自建部署用户**：服务端、网页端构建脚本已更新，一键打包产物统一输出到仓库根目录 `release/`
