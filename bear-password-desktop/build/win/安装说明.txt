BearPassword Windows 安装说明
============================

【推荐】安装程序（BearPassword-Setup.exe）
  1. 双击运行安装程序
  2. 按向导选择安装目录（可修改）
  3. 安装完成后可从开始菜单或桌面快捷方式启动

便携版（BearPassword-win-x64.zip）
  1. 解压 zip 到任意目录
  2. 运行 BearPassword.exe

说明
----
- 本安装包适用于 64 位 Windows 10 / 11（x64）
- 若 SmartScreen 提示「未知发布者」，请选择「仍要运行」或「更多信息」→「仍要运行」
- 首次使用前请确保后端服务已启动（默认 http://127.0.0.1:8080）
- 卸载：设置 → 应用 → 已安装的应用 → BearPassword → 卸载
