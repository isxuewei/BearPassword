核心功能

为日常登录而设计

从保存密码到网页填充，BearPassword 覆盖完整工作流，界面简洁、操作顺手。

密码库管理

集中管理登录凭据、自定义条目，支持搜索、收藏与最近访问，快速找到所需账号。

浏览器自动填充

扩展在登录页检测表单，显示填充图标，一键填入用户名与密码，工具栏徽章提示可用条目。

客户端加密

保险库内容在本地用安全密钥加解密，服务端仅存密文，解锁后方可查看明文密码。

自动锁定

闲置一段时间后自动锁定保险库，离开电脑时也能保护敏感数据，解锁需重新验证。

保存新凭据

提交登录表单后，扩展会提示将新账号保存到保险库，减少重复录入与遗忘风险。

丰富主题

内置十余款浅色与深色主题，从清新海洋到典雅紫韵，随心切换界面风格。

BearPassword 采用「服务端存储密文 + 客户端安全密钥解密」模型。 即使数据经过网络传输，明文密码也只在本地解锁后出现。

浏览器插件安装说明

下载后无需解压，开启开发者模式后直接拖入即可完成安装。

  1. 在 Chrome 地址栏输入 chrome://extensions 并回车
  2. 打开页面右上角的开发者模式
  3. 点击上方「浏览器插件」卡片下载，将文件直接拖入扩展管理页面
  4. 安装完成后，使用与桌面端相同的账号与安全密钥登录
